## 本地预览与视觉更新

2026-10-06：首页采用墨黑、银白与少量暖金；本地矢量曲面底图接入原有 WebGL 折射，保留原始图片。鼠标折射移除绿偏色和色散，降低染色高光；作品列表新增常驻缩略图，详情采用揭幕转场。手机端保留 DOM 标题，系统减少动态效果时使用静态展示。无需新增依赖。

滚动转场：首屏短暂停留并缩退、介绍幕布叠入、作品按滚动位置逐项展开，反向滚动可还原。触屏保留原生手势，减少动态效果时取消固定场景。

全局场景：参考 Remotion 展示页 Banger.Show 的放射式纵深视觉，自行实现银色立体叶片雕塑。使用本地 Canvas 投影绘制，滚动时从环形展开为波面，结尾收拢，带鼠标视差和背景暂停按钮；并未引入 Remotion 或复制其视频。隐藏页面/详情打开时暂停背景循环，减少动态效果时静态显示。

背景保留：原始 hero-main、hero-material、hero-closing 图片重新作为主背景，银色动画仅以低透明度叠加；原图文件未删除或覆盖。
